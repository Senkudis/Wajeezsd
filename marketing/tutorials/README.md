# فيديوهات شرح وجيز

ثلاثة فيديوهات أفقية (16:9، 1920×1080) بفصول، من شاشات التطبيق الحقيقي وبصوتٍ سوداني مسجَّل:

| الفيديو | السكربت | الناتج |
|---|---|---|
| العميل | `scripts/client.js` | `output/wajeez-client-tutorial.mp4` |
| الكابتن | `scripts/captain.js` | `output/wajeez-captain-tutorial.mp4` |
| التاجر | `scripts/merchant.js` | `output/wajeez-merchant-tutorial.mp4` |

## الخطوات

### 1. التسجيل (مرّة لكل فيديو)

```bash
node tools/studio.js
```

افتح `http://localhost:4310` في نفس الجهاز (الميكروفون يعمل على localhost فقط).
اختر الفيديو، واقرأ كل جملة كما هي على الشاشة، بلهجتك العادية وكأنك تشرح لصاحبك.

- **مسافة** تبدأ التسجيل وتوقفه، و**Enter** تنتقل للجملة التالية، و**P** تعيد سماع آخر تسجيل.
- كل جملةٍ تُحفظ وحدها في `vo/<video>/<id>.wav`، وتُنظَّف تلقائياً من الطنين والصمت ويتوحّد ارتفاع صوتها.
- لو ما عجبتك جملة سجّلها تاني، فالتسجيل الجديد يحل محل القديم.
- **احتفظ بنسخة من مجلد `vo/`** (درايف أو فلاشة): التسجيلات لا تُرفع للمستودع.
- يمكنك تعديل الكلام في السكربت ليطابق طريقتك في الكلام قبل التسجيل؛ المهم أن يطابق التسجيلُ النصّ لأن الترجمة على الشاشة تُؤخذ منه.

### 2. المراجعة

```bash
node tools/build.js client timeline
node tools/build.js client preview 5,40,120
node tools/build.js client render --draft
```

- `timeline` يحسب المدّة والفصول، ويكتب `output/client.srt` (ترجمة) و`output/client.chapters.txt` (فصول يوتيوب جاهزة للصق في الوصف).
- `preview` يحفظ إطاراتٍ في `scout/` لتراجعها.
- `node tools/review.js client` يأخذ إطاراً من كل مشهد ويجمعها في شبكات `scout/client-grid-*.jpg` لمراجعة الفيديو كله بنظرة.
- `--draft` يصنع نسخةً بنصف الدقّة وبسرعة.

قبل التسجيل يُقدَّر طول كل مشهد من عدد كلماته. بعد التسجيل يأخذ كل مشهد طول جملته الحقيقي.

### 3. النسخة النهائية

```bash
node tools/build.js client render
```

ينتج صورةً بدقّة 1080p، وموسيقى خلفية مؤلَّفة بالكود (بلا حقوق)، والصوت. تنخفض الموسيقى تلقائياً تحت الكلام، ويُطبَّع الارتفاع الكلّي على ‎-16 LUFS.

## إعادة تصوير الشاشات

الشاشات تُصوَّر من صفحات `public_html` الحقيقية ببياناتٍ تجريبية، ولا تتصل بالخادم ولا بقاعدة البيانات:

```bash
node tools/shots-client.js            # كل شاشات العميل
node tools/shots-captain.js           # الكابتن
node tools/shots-merchant.js          # التاجر
node tools/shots-client.js home,menu  # بعضها
```

`screens/<video>/MANIFEST.md` يصف كل شاشة وعناصرها. الشاشات والمخرجات لا تُرفع للمستودع (ثقيلة وتُولَّد من جديد).

تحتاج خادماً ثابتاً لـ `public_html` على المنفذ 4175 (أو `STATIC_PORT`). كل لقطة ينتج عنها ملفان:

- `screens/<video>/<name>.png`
- `screens/<video>/<name>.json`: مواضع العناصر التي تشير إليها النقرات والإبرازات في السكربت.

أعد تصوير الشاشات بعد أي تغييرٍ في واجهة التطبيق، ثم أعد البناء.

## بنية السكربت

```js
{ id: 'c-order-3', chapter: 2, screen: 'client/orderForm.png',
  title: 'السعر عليك', points: ['اقتراح تلقائي', '! ما تنزل تحت الحد'],
  vo: 'الجملة بالسوداني…', tone: 'هادئ',
  scroll: [[0, 900], [0.3, 1250]],          // [نسبة من المشهد، بكسل CSS]
  hl: [{ at: 'price', w: 'سعر' }],          // إبرازٌ يبدأ حين تُقال الكلمة «سعر»
  taps: [{ at: 'plus', w: 'بالزائد' }],     // نقرةٌ عند الكلمة
  zoom: { at: 'price', s: 1.6 } }           // تكبير
```

- `at` اسم عنصرٍ من ملف الـ json الخاص بالشاشة، أو مستطيل `{x,y,w,h}`.
- `w` كلمةٌ من الجملة: الإبراز يبدأ عند موضعها في الكلام ويبقى حتى الإبراز التالي، فيتزامن مع صوتك بعد التسجيل. وإن عدّلت الجملة فأبقِ الكلمة، وإلا نبّهك `timeline`. (`t` و`until` كنسبٍ من المشهد ما زالا متاحين.)
- في السكربتات تجد الحركات مجمّعة في `FX` آخر الملف، والكلام والعناوين في `scenes`.
- النقطة التي تبدأ بـ «!» تظهر كتنبيه.
- أنواع البطاقات: `cover` و`agenda` و`chapter` و`outro`.
